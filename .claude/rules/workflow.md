# Работа по этапам
- Перед действием читай текущий согласованный результат и зависимости предыдущих этапов (папка `project-docs/`).
- На этапе «Идея» определяется продукт; на этапе «Образ сайта» — впечатление и характер подачи; на этапе «Карта сайта и действий» — страницы, функции и переходы; на этапе «Визуальные правила» — точное оформление.
- Не писать код и не запускать сборку до отдельного запроса после согласования первых четырёх результатов.
- Результат каждого этапа сохранять отдельным документом в `project-docs/`; не изменять исходные файлы-инструкции курса.
- Не перезаписывать прежние результаты: новая редакция — новое свободное имя (`_v02`, `_v03`…).
- Не заполнять пробелы предположениями; предлагать 2–3 варианта и уточнять по одному вопросу.
- После каждого утверждённого результата запускать навык update-project-context и обновлять только подтверждённые сведения в CLAUDE.md и профильных rules.
- Если решения противоречат друг другу, сначала объяснить конфликт и запросить выбор; не исправлять документы молча.
