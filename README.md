# Blush-Berry

Сайт авторской кондитерской Blush-Berry: посетитель собирает торт в калькуляторе, видит примерную цену и отправляет готовое сообщение в Telegram.

Статичный сайт без сборки и зависимостей — папка `site/`. Открыть локально: `site/index.html` в браузере.

- `site/` — сайт (HTML, CSS, JS, шрифты)
- `site/js/config.js` — цены, сроки и Telegram; значения с пометкой ⚠ — черновые
- `project-docs/` — согласованные документы проекта и статус сборки

Сайт ничего не хранит и не собирает; секретных ключей не требует.

Шрифты Cormorant Garamond и Manrope — SIL Open Font License, тексты лицензий в `site/fonts/`.
